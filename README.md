# 📚 Minha Trajetória de Estudos em AWS — Bancos de Dados

Durante este módulo aprendi sobre os principais serviços de banco de dados da AWS e quando utilizar cada um deles de acordo com a necessidade da aplicação.

O curso apresentou desde conceitos iniciais até serviços gerenciados e bancos NoSQL, mostrando cenários reais de uso em sistemas escaláveis na nuvem.

---

## 🧠 Conceitos Iniciais

- Introdução ao ecossistema de bancos de dados da AWS
- Diferença entre bancos relacionais, NoSQL e Data Warehouse
- Quando escolher cada tipo de banco de dados
- Vantagens de serviços gerenciados (alta disponibilidade, escalabilidade e manutenção automática)

---

## 🏢 Amazon Redshift (Data Warehouse)

Banco de dados relacional focado em análise de grandes volumes de dados.

### O que aprendi
- Utilização de SQL para análise de dados
- Armazenamento otimizado para BI e Analytics
- Processamento de grandes quantidades de informação
- Cenários de uso: relatórios, dashboards e análise empresarial

---

## 🗄️ Amazon RDS (Relational Database Service)

Serviço gerenciado de banco de dados relacional.

### Recursos estudados
- Criação e gerenciamento de instâncias
- Réplicas de leitura para melhorar desempenho
- Multi-AZ para alta disponibilidade
- Backups automáticos e recuperação
- Redução de trabalho operacional do DBA

### Benefícios
- Escalabilidade automática
- Manutenção simplificada
- Segurança gerenciada pela AWS

---

## ⚡ Amazon DynamoDB (NoSQL)

Banco de dados NoSQL totalmente gerenciado e altamente escalável.

### Conceitos importantes
- Tabelas, atributos e chaves primárias
- Índices secundários
- Query vs Scan
- Performance previsível em grande escala

### Também aprendi
- Modelo de precificação
- Quando usar NoSQL ao invés de relacional
- Aplicações em sistemas de alta demanda (ex: apps em tempo real)
